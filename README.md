# Photo Sorter

Консольная утилита на Python для упорядочивания личного архива фотографий и видео. Программа рекурсивно просматривает исходную папку, определяет наиболее подходящую дату и раскладывает файлы по структуре **год → месяц → день**.

Проект рассчитан прежде всего на **Windows** и помогает постепенно разбирать большой архив, не смешивая файлы с достоверной датой съёмки и файлы с менее надёжной датой.

## Как устроена сортировка

Источники даты проверяются по приоритету:

| Приоритет | Источник | Каталог назначения |
| --- | --- | --- |
| 1 | Дата съёмки из метаданных фотографии или видео | `Фото/ГОД/месяц/день/` |
| 2 | Дата, распознанная в имени файла | `Фото/фото_по_имени/ГОД/месяц/день/` |
| 3 | Дата создания файла в Windows | `Фото/сомнительные_фото/ГОД/месяц/день/` |

Если метаданные содержат подходящую дату съёмки, она имеет приоритет над именем файла. Даты из имён и файловой системы не попадают в основной архив.

Пример результата:

```text
Фото/
├── 2015/
│   └── январь/
│       └── 18/
│           └── 2015_01_18_пельмениссимо_003.JPG
├── фото_по_имени/
│   └── 2026/
│       └── ноябрь/
│           └── 05/
│               └── photo_2026-11-05_18-23-35.jpg
└── сомнительные_фото/
    └── 2024/
        └── июнь/
            └── 10/
                └── DSC_0012.jpg
```

Вторая и третья ветки позволяют позже отдельно проверить файлы, чья дата не подтверждена метаданными съёмки.

## Поддерживаемые форматы

- **Фото:** JPG, JPEG, PNG, HEIC, HEIF, TIF, TIFF, WEBP, BMP, GIF.
- **Видео:** MP4, MOV, AVI, MKV, M4V, 3GP, MTS, M2TS, WMV, MPG, MPEG.

Наличие расширения не гарантирует наличие даты съёмки: это зависит от метаданных конкретного файла.

## Требования

- Windows.
- Python **3.11+**.
- [ExifTool](https://exiftool.org/) для чтения метаданных.

Скачайте ExifTool для Windows, распакуйте и переименуйте `exiftool(-k).exe` в **`exiftool.exe`**. В командах ниже укажите путь к этому файлу. Если ExifTool добавлен в `PATH`, аргумент `--exiftool` можно опустить.

Проверка установки в Git Bash:

```bash
py --version
"C:/tools/exiftool/exiftool.exe" -ver
```

Скрипт использует стандартную библиотеку Python; устанавливать дополнительные Python-пакеты не требуется.

## Запуск

Откройте Git Bash или PowerShell в папке проекта. Замените пути в примерах на свои.

### 1. Предварительный просмотр — рекомендуется начать с него

```bash
py sort_photos.py \
  --source "C:\Users\user\Pictures\Unsorted" \
  --target "D:\Фото" \
  --exiftool "C:\tools\exiftool\exiftool.exe" \
  --dry-run
```

`--dry-run` **ничего не копирует и не перемещает**. Это также режим по умолчанию, если не указан режим действия.

### 2. Копирование с сохранением оригиналов

```bash
py sort_photos.py \
  --source "C:\Users\user\Pictures\Unsorted" \
  --target "D:\Фото" \
  --exiftool "C:\tools\exiftool\exiftool.exe" \
  --copy
```

### 3. Перемещение

```bash
py sort_photos.py \
  --source "C:\Users\user\Pictures\Unsorted" \
  --target "D:\Фото" \
  --exiftool "C:\tools\exiftool\exiftool.exe" \
  --move
```

В режиме `--move` исходный файл удаляется только после копирования и проверки совпадения SHA-256.

### Аргументы командной строки

| Аргумент | Назначение |
| --- | --- |
| `--source` | Исходная папка; обязательный параметр |
| `--target` | Корень архива; обязательный параметр |
| `--exiftool` | Путь к `exiftool.exe`; по умолчанию поиск в `PATH` |
| `--dry-run` | Предварительный просмотр (по умолчанию) |
| `--copy` | Копирование с сохранением исходников |
| `--move` | Перемещение файлов |
| `--report` | Путь к CSV-отчёту |

Режимы `--dry-run`, `--copy` и `--move` взаимоисключающие.

## Отчёт и защита данных

После запуска создаётся CSV-отчёт `photo_sort_report_ГГГГММДД_ЧЧММСС.csv` в текущей рабочей папке (или по пути `--report`). В нём записываются исходный и целевой пути, дата, её источник, категория, действие, статус и детали.

- Существующие файлы **не перезаписываются**.
- Если имя совпало, но содержимое отличается, подбирается новое имя с суффиксом `__1`, `__2` и т. д.
- Совпадающие по содержимому файлы при проверке конфликта считаются дубликатами; исходник не удаляется.
- Целевая папка исключается из рекурсивного обхода, если она находится внутри исходной.
- Ошибки отдельных файлов записываются в отчёт, обработка остальных продолжается.

**Ограничения:** проверка дубликатов выполняется при выборе пути назначения, а не как глобальный поиск одинаковых файлов во всём архиве. В режиме предварительного просмотра конфликты между несколькими новыми файлами могут отображаться иначе, чем при реальном копировании. При ошибке копирования частичный файл может остаться в целевой папке — проверяйте отчёт. Даты видео могут зависеть от часового пояса в метаданных; дату создания файла Windows также нельзя считать гарантированной датой съёмки.

Для первого реального запуска используйте `--copy` на небольшой папке, проверьте результат и только затем переходите к большому архиву или `--move`. Желательно иметь резервную копию исходных фотографий.

```bash
py -m unittest -v test_sort_photos.py
```

## Структура репозитория

```text
photo-sorter/
├── sort_photos.py
├── test_sort_photos.py
├── README.md
└── .gitignore
```

Не добавляйте в репозиторий личные фотографии, CSV-отчёты, временные файлы и папки `__pycache__`.

## Идеи для развития

- Пакетное чтение метаданных для ускорения работы с большими архивами.
- Дополнительные тесты с реальными форматами фотографий и видео.
- Более подробная диагностика конфликтующих дат и часовых поясов.
- Возможность повторной проверки категории `сомнительные_фото`.

## Статус

Личный проект для постепенной сортировки существующего фото- и видеоархива. Первая рабочая версия; поведение на нестандартных файлах проверяется по мере использования.
